模型Models

数据模型

会预测

凭历史数据学规律，回答「大概率会怎样」。

  • 缺陷概率预测 逐箱输出
  • 参数响应建模 候选搜索
  • 候选参数 + 目标分 带置信度

载体：信智 HiAI · LightGBM 等
短板：分布外不可靠 → 须机理兜底

机理模型

守边界

按发泡物理化学规律，回答「物理上能不能」。

  • 可行域与硬约束 参数窗口
  • 过程状态估计 孪生对照
  • 异常物理解释 温度场对照

形态：机理孪生 · 约束框架
权力：否决 · 修正 · 解释

大语言模型

懂现场

认知与协同层，回答「为什么、怎么办、怎么说清」。

  • 私域知识问答 RAG 检索
  • 根因叙事与报告 引用证据
  • 多步骤任务编排 HiAgent

部署：私有化优先（千问 / DeepSeek 等）
定位：不计算、不控制、不改判等级

＋ 感知侧还有第四个模型 —— 气泡识别模型（在 L3 感知检测层，见下），负责把热像变成可用的缺陷标签。

标签、温度场、检测摘要自感知层三方供数至三模型

检测Sense

5 路红外热成像

顶视 1 路 ＋ 四侧各 1 路，同步采集；与条码、型号、工艺参数按时间戳逐箱对齐。任一路故障只标「检测不完整」，不出合格结论。

气泡识别模型 · 三段式（边缘推理，单箱 ≤ 3 秒）

定位检测（位置与轮廓）→ 特征量化（数量 · 面积占比 · 最大尺寸 · 分布密度 · 温差）→ 等级分类（等级 ＋ 置信度，低置信强制待复核；超时转人工队列，不堵节拍）

B 级通过 · 观察

D 级拦截 · 复核处置

AI 初筛 ＋ 人工复核

模型不单独作报废决定；复核员可推翻等级，推翻样本留存为训练标注，持续回训气泡模型。

→ 数据模型：分级与量化特征作缺陷标签，解冷启动缺标签 → 机理模型：实测温度场与气泡分布逐箱对照 → 语言模型：结构化检测摘要供根因叙事，不得改判等级

安全下发闭环（唯一通道）

参数白名单 → 人工确认 → 下发 → 回读验证 → 效果验证 → 不达标可回滚，全程审计。LLM 不直连 PLC · 不动运行中的优化块 DB · 生产数据不上公网大模型。

双轨验证（不冒充已达标）

协议轨对技术协议逐项验收，灯塔轨对灯塔工厂标准；未验证指标记为「未验证」。气泡模型单独成套验证，D 级漏检一票否决。

读图顺序：自下而上看供数（L1 → L4），自上而下看决策（L6 → L1），中间 L5 是唯一的裁决点。 现状口径：数据模型为规则占位、机理为约束框架、气泡模型待训练验证、LLM 深化属阶段 3–4 规划 —— 本图为设计目标架构。
